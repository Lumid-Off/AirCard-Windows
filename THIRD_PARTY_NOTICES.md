## Card Design Generator

The integrated crop/layout workflow is inspired by **Susie-Meow/card-design-generator**.

Repository: https://github.com/Susie-Meow/card-design-generator  
Live demo: https://susie-meow.github.io/card-design-generator/

The upstream project describes a fixed ISO 7810 ID-1 card-ratio workflow with background crop, reference image, logo layers, opacity/rotation/background removal/outline, and local export. The AirCard implementation in this patch is a native Rust/egui implementation adapted for Wallet output rather than an embedded copy of the website.
